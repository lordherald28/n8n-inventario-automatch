# AutoMatch — n8n Inventario

Repositorio inicial para el proyecto AutoMatch relacionado con inventario. En esta etapa contiene únicamente el AI Engineering Harness y las convenciones de trabajo.

## Alcance de esta inicialización

- Ramas base: `main` (estable) y `dev` (integración).
- Desarrollo por objetivos ODD, con verificación reproducible y aprobación humana para integrar a `main`.
- No se incluyen workflows, reglas de negocio, endpoints ni lógica de inventario.

Consulta [AGENTS.md](AGENTS.md), [Git Flow](docs/git-flow.md) y [estructura del proyecto](docs/project-structure.md) antes de trabajar.

## Visibilidad y permisos

Este repositorio es público y cualquier persona puede clonarlo y leer su contenido. La visibilidad pública no concede permiso de escritura sobre el repositorio original. Los colaboradores con escritura deben gestionarse explícitamente en GitHub. Terceros también pueden proponer cambios mediante forks y Pull Requests, que requieren revisión y aprobación antes de integrarse.
